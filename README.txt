PTS UNIVERSAL OFFLINE — VERSI LENGKAP — SMK ISMAILIYAH

Cara memakai:
1. Ekstrak ZIP.
2. Buka index.html dengan Chrome, Edge, Firefox, atau browser modern lain.
3. Tidak perlu internet.
4. Klik Panel Admin/Guru untuk mengelola bank soal, peserta, paket ujian, hasil, dan backup.
5. Buat paket ujian, pilih soal, lalu peserta dapat mulai dari menu Mulai Ujian.

FITUR:
- Dashboard ujian
- Data peserta + kode peserta
- Paket ujian per mapel
- Timer otomatis dan pengumpulan otomatis
- Acak soal dan opsi
- Bank soal manual/edit/hapus
- Import TXT, CSV, DOCX, XLSX, PDF teks, dan gambar
- Nilai otomatis, KKM, status lulus/belum lulus
- Riwayat hasil
- Cetak hasil
- Export rekap CSV
- Backup/restore seluruh data JSON
- Password admin lokal (opsional)
- Semua data tersimpan di perangkat/browser dan tidak dikirim ke internet

FORMAT IMPORT TXT/DOCX/CSV/XLSX:
1. Ibukota Indonesia adalah ...
A. Jakarta
B. Bandung
C. Surabaya
D. Malang
Kunci: A

Catatan: PDF scan/foto mungkin tidak bisa diekstrak tanpa OCR. File gambar ditambahkan sebagai media soal dan dapat dilengkapi opsi/kunci melalui Bank Soal.
